# 四份实习周记版式基准

- 设计依据：以提交目录中用户已调整的《第1周实习记录.docx》为唯一视觉模板。
- 纸张：A4，纵向；页面约 11906 × 16838 twips。
- 页边距：左、右约 2.55 cm；上约 2.35 cm；下约 2.25 cm；页眉、页脚约 1.20 cm。
- 标题：方正小标宋简体，16 pt，加粗，居中；仅保留“第N周实习记录”，不设副标题。
- 正文与信息表：仿宋_GB2312，12 pt；正文两端对齐、首行缩进约 2 字符。
- 一级栏目：仿宋_GB2312，12 pt，加粗。
- 信息表：2 × 4，列宽约 1669 / 2670 / 1669 / 3006 DXA，细灰边框、无底纹、垂直居中。
- 页脚：底部居中动态页码。
- 视觉原则：白底黑字，不使用色块、装饰页眉或信息卡片；四份保持相同层级、字体、间距和表格几何。
- 内容原则：事实可核验，保留关键分母、样本量、异常处理、反证和限制；不虚构公司任务、老师评价或自然周日期。
